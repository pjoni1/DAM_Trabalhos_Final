# API Usage

## API Endpoint
`GET https://api.unsplash.com/photos` (ou um endpoint similar da REST API pretendida)

## Response Format
O formato de resposta padrão utilizado e recebido pelas instâncias Retrofit na nossa aplicação será o **JSON**.

## Example JSON Response
```json
[
  {
    "id": "LBI7cgq3pbM",
    "url": "https://images.unsplash.com/photo-1...",
    "title": "Beautiful scenery"
  },
  {
    "id": "xN6P_l_wEPE",
    "url": "https://images.unsplash.com/photo-2...",
    "title": "Urban architectural view"
  }
]
```
